# Free font shortlist

Use this only when the owner has no font files and names no free font (font policy path (c) in `SPEC.md`, step 3 of `skills/bam--intake.md`). Suggest up to three pairs from this list, each with one sentence tying it to the brand. The owner chooses. The choice stays **we guessed** (`derived`, `source: suggested`) until a post that uses it is picked.

Every font here is under the SIL Open Font License 1.1 (OFL 1.1): free to use, embed and ship with your brand files, as long as its licence file goes with it. Download from the source link, keep the licence file beside the font in `brand/fonts/`, and write the name, licence and link in `brand/fonts.md`.

Each pair has a display face (headings and big numbers) and a body face (everything else). Both must have the weights your brand file names.

## How to suggest

1. Read the brand's three tone words and its audience line.
2. Pick at most three pairs. For each, write one sentence that ties it to those words ("Fraunces: warm and a little old-fashioned, like the 'warm' in your tone words").
3. Show each pair with the brand's own headline, not a pangram.
4. Wait for the owner to choose. Never pick silently.
5. Record it in `brand/fonts.md`: `source: suggested`, the names, OFL 1.1, the source links, and the status **we guessed** (`derived`).

## Never

- Never suggest a font that is not on this list without checking its licence file yourself. "Free to download" is not a licence.
- Never suggest a pair whose display and body faces are the same weight of the same family. The `role-face` check needs two faces to tell apart, unless the owner names one face for both.
- Never mark a suggested font as **you said** (`locked`) before a post that uses it is picked.
